# 시장 밸런스 패치 v20

## 2026-09-20 전설 포켓몬 시작가 평균 조정

이번 패치는 **전설 포켓몬의 시작가 평균만** `125,000 TC`에서 **`150,000 TC`**로 변경한다.
일반 / 환상 시작가와 v19의 전설 장기 가격 밸런스는 그대로 유지한다.

```js
legendary: { average: 150000, ... }
```

새 시장 생성 또는 시장 초기화 시 전설 포켓몬별 가중치가 적용되며, **전설 등급 전체 평균이 약 150,000 TC**가 되도록 시작 가격이 계산된다.
기존 저장 데이터의 이미 생성된 전설 가격은 자동으로 재계산하지 않는다. 새로운 시작가를 확인하려면 시장 데이터를 초기화해야 한다.

# 이전 v19 전설 장기 밸런스

## 2026-09-20 전설 포켓몬 기술주형 장기 밸런스

이번 패치는 **전설 포켓몬만** 추가 조정한다.
일반 / 환상 포켓몬과 뉴스 밸런스는 v18 값을 그대로 유지한다.

전설 포켓몬의 목표는 실제 주식으로 치면 **중소·중견 기술 성장주**다.
장기간 크게 성장해 대기업 수준 가격까지 갈 수 있지만, 항상 고성장하는 것은 아니며 하락 시 중소기업 수준까지 내려갈 수도 있게 한다.

## 전설 장기 상승 억제

전설 포켓몬의 시작가를 장기 앵커로 사용한다.
하드캡 없이 시작가 대비 수익률이 커질수록 하락 압력 발동 확률을 높인다.

| 시작가 대비 수익률 | 가격 배수 | 하락 압력 발동 확률 |
| --- | ---: | ---: |
| `+200% 이상` | 시작가의 `3배 이상` | `20%` |
| `+500% 이상` | 시작가의 `6배 이상` | `50%` |
| `+1000% 이상` | 시작가의 `11배 이상` | `85%` |

예를 들어 시작가가 `150,000 TC`라면:

- `450,000 TC` 이상: 20% 확률 하락 압력
- `900,000 TC` 이상: 50% 확률 하락 압력
- `1,650,000 TC` 이상: 85% 확률 하락 압력

가격을 특정 TC로 고정하는 하드캡은 없다.
시장 상황과 뉴스가 좋으면 더 크게 성장할 수 있지만 높은 구간일수록 장기 과열이 지속되기 어려워진다.

## 전설 장기 하락

- `recoveryBasePrice` 대비 `-50%` 이하
- `20%` 확률로 상승 복원 압력

하락 복원을 약하게 두어 전설 포켓몬이 장기간 부진할 경우 중소기업 수준 가격까지 내려갈 수 있게 한다.

## 전설 Tick당 상승 속도

- 평상시 한 Tick 최대 상승: **`+15%`**
- 하락 Tick 제한: 없음
- 전설 상승 Shock: 기존 **`+10% ~ +50%`** 유지

상승 Shock은 기술주의 실적 발표·신기술 기대감 같은 드문 급등으로 보고 `+15%` 제한의 예외로 허용한다.
Shock이 아닌 뉴스 / Momentum / 시장 상태가 겹친 일반 상승은 한 Tick 최대 +15%까지만 반영한다.

## 전설 recoveryBasePrice 추종 속도

- 기존 공통값: 가격 차이의 `0.5%`
- 전설: 가격 차이의 **`0.2%`**

지속적인 장기 성장은 기준가가 어느 정도 따라가지만, 단기 급등이 즉시 새로운 정상 가격으로 굳는 현상은 줄인다.
가격이 하락해도 recoveryBasePrice가 내려가지 않는 기존 규칙은 유지한다.

## 일반 / 환상 설정 유지

### 일반

- 동전주/지폐주형 `+100% ~ +250%` Shock
- Shock 상승분 10 Tick 복원
- 장기 하락 압력: `+200% → 30%`, `+400% → 60%`, `+500% → 90%`
- recoveryBasePrice 추종: `0.1%`

### 환상

- 급등 복원: 기준가 대비 `+15% → 30%` 확률 하락 압력
- 급락 복원: 기준가 대비 `-20% → 20%` 확률 상승 압력
- 한 Tick 최대 상승: `+10%`
- recoveryBasePrice 추종: `0.05%`
- 가격 하드캡 없음

## 그대로 유지되는 주요 시장 밸런스

- 뉴스 비율: `중립 30% / 호재 50% / 악재 20%`
- Global Growth: Tick당 `+0.0003%`
- 일반 Shock 확률: `0.04%`
- 전설 Shock 확률: `0.02%`
- 환상 Shock 확률: `0.015%`
- 호재 해당 스토리 타입: `-1% ~ +10%`
- 호재 특정 포켓몬: `-1% ~ +9%`
- 호재 실제 약점 포켓몬: `-4% ~ +0.5%`
- 악재 해당 스토리 타입: `-13% ~ +1%`
