# MARKET NEWS 및 시장 상태 UI 수정

## 작업 목적

MARKET 화면에서 아래 2가지만 수정한다.

1. MARKET NEWS 영역의 높이와 뉴스 저장 개수 변경
2. 화면에 표시되는 전체 시장 상태 UI 제거

시장 가격 계산식, 시장 상태 계산, 뉴스 발생 규칙은 변경하지 않는다.

---

# 1. 작업 전 확인

코드를 수정하기 전에 아래 파일을 확인한다.

- `index.html`
- `css/style.css`
- `js/market-view.js`
- `js/market.js`
- `js/storage.js`

확인할 내용:

1. MARKET NEWS HTML이 `index.html`에 있는지 JS에서 생성되는지
2. 뉴스 배열이 어느 파일에서 관리되는지
3. 뉴스 객체에서 발생 시간을 저장하는 기존 필드가 무엇인지
4. 뉴스가 localStorage에 어떤 형태로 저장되는지
5. 전체 시장 카드와 시장 상태 설명 텍스트를 어느 코드에서 출력하는지

기존 필드가 있으면 그대로 사용한다.
같은 역할의 새 데이터 필드나 새 JS 파일을 만들지 않는다.

---

# 2. MARKET NEWS 데이터 규칙

시장 뉴스 데이터는 최대 5개만 저장한다.

뉴스가 새로 발생할 때 다음 순서로 처리한다.

```text
새 뉴스 발생
↓
기존 뉴스 데이터에 추가
↓
뉴스 개수가 5개를 초과했는지 확인
↓
5개 초과
→ 가장 오래된 뉴스 삭제
↓
최신 뉴스 5개만 유지
↓
저장
