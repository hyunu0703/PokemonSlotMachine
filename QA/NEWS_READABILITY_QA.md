## 수정 원칙

- 주요 인물 이름은 줄이거나 생략하지 않는다.
- 제목의 지역/인물/후속 문구 중복을 줄인다.
- 설명은 최대 3문장으로 제한한다.
- 이전 뉴스 제목 전체를 다음 설명에 반복하지 않는다.
- event가 없는 Stage도 문장 조각이 아니라 완전한 설명 문장으로 만든다.
- `~때문'라는 설명`, `~위해서'라는 설명` 같은 어색한 이유 문장을 제거한다.
- `후속:` / `후일담:`처럼 자동 후속 표기와 겹치는 접두어를 제거한다.
- 지역, 장소, 주요 인물, 스토리명, 포켓몬/타입 키워드는 기존 UI의 굵기 강조 기능을 유지한다.

## 굵기 표시 확인

현재 `js/market-view.js`에는 이미 뉴스 핵심 키워드 강조 기능이 있다.

- 뉴스 제목: `<strong>`으로 전체 굵게 표시
- 설명문: `appendHighlightedText()`에서 핵심 키워드를 `market-news-keyword` span으로 분리
- 굵기 CSS: `.market-news-keyword { font-weight: 900; }`
- 강조 대상: 스토리명, 지역명, 주요 인물(`sixW.who`), 장소(`sixW.where`), 포켓몬명, 타입

수정된 문장에서도 지역/장소/주요 인물을 원문 그대로 유지하므로 기존 강조 로직이 그대로 작동한다.
사건은 뉴스 제목 전체가 `<strong>`으로 표시되므로 별도의 HTML 삽입 없이도 핵심 사건명이 굵게 보인다.
