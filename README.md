# Pokémon Slot Collection

`index.html`을 더블 클릭해서 열지 마세요. 브라우저 보안 정책 때문에 로컬 JSON 도감을 읽을 수 없습니다.

프로젝트 폴더의 `Start-Server.cmd`를 더블 클릭하세요. 브라우저에서 `http://127.0.0.1:4173`이 열리면 게임을 사용할 수 있습니다. 검은 창은 서버가 실행 중인 동안 열어 두고, 종료하려면 그 창에서 `Ctrl+C`를 누르세요. 별도 설치는 필요 없습니다.

MARKET은 카드 가격 확인과 판매 전용입니다. 초기 자금은 500,000 TC이며 일반/전설/환상 슬롯 비용은 각각 1,000/25,000/150,000 TC입니다. 중복 카드를 획득할 수 있고, 모두 팔아도 도감 등록은 유지됩니다.

시장은 PC 시간 기준 10분마다 진행되며, 종료 중 경과 시간도 다음 접속 때 반영합니다. 뉴스는 매일 08시·12시·18시에 확률적으로 발생합니다. 가격 기록은 최근 145개(최대 24시간), 뉴스 이력은 40개를 보관합니다. ALL 차트도 보관된 기록 전체를 뜻합니다.

저장은 기존 localStorage 키 `pokemonSlotSaveV1`의 version 2 형식입니다. 기존 version 1 수집 카드는 각 1장으로 이전됩니다. 설정의 게임 초기화는 수집·보유량·TC·시장 전체에 적용됩니다. 재화가 부족하면 보유 카드를 판매해야 하며, 무료 재지급 기능은 없습니다.

검증: `node tests/market.test.mjs`. 브라우저 검증은 Playwright와 Edge가 있는 개발 환경에서 `node tests/browser.test.cjs`로 실행합니다. Playwright가 외부 경로에 설치되어 있으면 `PLAYWRIGHT_MODULE`에 해당 패키지 폴더를 지정하세요. 검증 서버는 별도 포트 4174와 임시 브라우저 세션을 사용하므로 실제 플레이 저장에 영향을 주지 않습니다.
