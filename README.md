# Pokémon Card Virtual Investment Simulator

본 프로젝트는 대학교 과제 제출을 목적으로 제작된 비상업적 프로젝트입니다.
Pokémon 및 관련 캐릭터, 명칭, 이미지 등의 
저작권과 상표권은 The Pokémon Company 및 각 권리자에게 있습니다.
본 프로젝트는 Pokémon 공식 서비스와 관련이 없습니다.

또한 본 프로젝트의 인터넷 및 커뮤니티를 통한 홍보, 재배포, 무단 공유를 원하지 않습니다.
프로젝트 파일 및 소스 코드를 작성자의 허가 없이 별도로 배포하지 말아주세요.

본 프로젝트는 개인적인 이용을 목적으로 제공하고 있습니다.
작성자의 허가 없이 다른 사람에게 공유하거나 배포하지 마시고, 개인적인 범위에서 이용해주세요.


# 프로젝트 소개 

Pokémon Card Virtual Investment Simulator는
포켓몬 카드 수집과 가상 모의투자를 결합한 웹 기반 시뮬레이션 프로젝트입니다.

사용자는 슬롯을 통해 포켓몬 카드를 획득하고,
가상 시장에서 카드 가격 변동을 확인하며 카드를 사고팔 수 있습니다.

수집한 카드의 보유 현황과 평균 매입가, 평가 금액, 수익률 등을 확인할 수 있으며,
실제 투자처럼 가격 변화와 거래 결과를 경험할 수 있도록 구현했습니다.

모든 거래는 가상 크레딧으로 이루어지며, 실제 금전 거래나 실제 포켓몬 카드 시세와는 관련이 없습니다.


# 실행 방법 

본 프로젝트는 아래 두 가지 방법으로 실행할 수 있습니다.

개발자가 의도한 포켓몬 카드 수집 + 가상 모의투자 시뮬레이션은 아래 배포 사이트에서 이용할 수 있습니다.

1. https://pokemon-slot-machine-phi.vercel.app/

별도의 설치 없이 웹 브라우저에서 바로 실행할 수 있습니다.


2. Start-Server.cmd는 로컬 웹 서버를 실행하여 프로젝트를 개발자 모드로 확인할 수 있도록 합니다.

브라우저 보안 정책 및 로컬 파일 접근 제한으로 인해 index.html을 직접 실행하면 일부 기능이 정상적으로 동작하지 않을 수 있으므로, 로컬 실행 시에는 반드시 Start-Server.cmd를 사용해주세요.

일반적인 이용은 배포된 웹사이트를 권장하며, Start-Server.cmd는 프로젝트 개발 및 로컬 테스트를 위한 실행 방식입니다.


# 데이터 저장 안내

본 프로젝트의 게임 진행 데이터는 서버나 사용자 계정에 저장되지 않으며,
현재 사용 중인 브라우저의 로컬 저장소(LocalStorage)​에 저장됩니다.

따라서 저장 데이터는 PC와 브라우저 환경마다 서로 독립적으로 관리됩니다.

예를 들어 같은 PC에서도 Chrome과 Microsoft Edge의 저장 데이터는 서로 다르며,
같은 Chrome을 사용하더라도 서로 다른 브라우저 프로필에서는 별도의 데이터가 저장됩니다.

또한 동일한 Google 계정으로 로그인하더라도 다른 PC에서 접속하면 기존 게임 데이터가 자동으로 공유되지 않습니다.

브라우저의 사이트 데이터 또는 LocalStorage를 삭제할 경우 기존 진행 데이터가 초기화될 수 있으니 주의해주세요.

현재 본 프로젝트는 PC 환경을 기준으로 제작되었으며, 모바일 환경은 추후에 제작하도록 하겠습니다.
